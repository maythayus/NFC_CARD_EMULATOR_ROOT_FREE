NFC CARD EMULATOR ROOT FREE
Android app for NFC testing and analysis, focused on HCE ISO-DEP (APDU), with card profile management and MIFARE Classic dump import for comparison/diagnostics.

Features
Card profile management
Add / remove cards
Select an active card
Backup / restore profiles via JSON
Dump import
Import VIGIK JSON dumps (format vigik_badge_*.json generated by tools/vigik_verify.py read)
Import Proxmark3 mfcard JSON dumps (e.g. hf-mf-XXXX-dump.json with Card.UID + blocks)
Import raw dumps (.dump 1K) and wrap them as raw/base64
HCE ISO-DEP emulation (Host Card Emulation)
APDU responses compatible with tools/vigik_verify.py hce:
SELECT AID
GET UID (00CA)
READ (00B2 sector/block) returning 16 bytes from the attached dump
Proprietary demo protocol (AES-GCM)
AID: F04E4643454D5531 ("NFCEMU1")
PC/SC test script: tools/isodep_proto_verify.py
Built-in application logs
View, copy, clear, export (SAF)
VIGIK / VIGIK+ Compatibility
This application does not clone a VIGIK badge and does not implement MIFARE Classic Crypto-1 authentication.

Compatible (PC/SC / ACR122U tests):
The HCE ISO-DEP part works with readers/systems that accept APDU exchanges.
The script tools/vigik_verify.py hce verifies that the phone responds correctly to APDU commands (SELECT/UID/READ) based on an imported dump.
Important limitations (VIGIK / VIGIK+):
Many VIGIK/VIGIK+ installations rely on MIFARE Classic and therefore Crypto-1.
In that case, the reader expects Crypto‑1 authentication (not ISO‑DEP APDU frames) and standard Android HCE cannot emulate it.
In short:

If your gate/reader uses ISO-DEP/APDU: HCE tests are likely to work.
If your gate/reader uses MIFARE Classic (Crypto‑1): ISO‑DEP HCE alone is not enough.

Usage
1) Import a dump
In the app:

Import a vigik_badge_*.json (recommended)
or a hf-mf-XXXX-dump.json (Proxmark3)
or a raw .dump
Attach the dump to the active card (or use auto-attach/auto-restore if enabled).

2) Test HCE emulation ("vigik" mode)
From tools/:

bash
python vigik_verify.py hce
3) Test the proprietary AES-GCM protocol
From tools/:

bash
python isodep_proto_verify.py
Security Notes
Do not hardcode secrets (AES key) in a production app.
The provided AES-GCM protocol is a technical demonstration for a system you control (reader + app), not a bypass of existing systems.
