# NFC_CARD_EMULATOR_ROOT_FREE
Application Android de test et d’analyse NFC, centrée sur HCE ISO-DEP (APDU). Gestion de profils de cartes, import de dumps (VIGIK JSON/Proxmark3/.dump), réponses SELECT/UID/READ, protocole démo AES-GCM, logs intégrés et outils Python pour valider les échanges via lecteur PC/SC.
